# ML — формулы и книги

Статическая учебная библиотека по машинному обучению. Проект разделяет два режима:

- **Formula Wiki** — одно каноническое объяснение каждой формулы: обозначения, смысл, числовой пример и исполняемый Python-код;
- **Books** — последовательные конспекты книг, где та же формула показана в контексте главы и страницы.

Каждая книжная карточка ведёт в общую статью формулы, а общая статья показывает все места, где формула встречается в книгах.

**Сайт:** https://qwert11.github.io/ML/

## Разделы

```text
/ML/                                         — главная страница
/ML/Formula-Wiki/                            — каталог общих формул
/ML/Formula-Wiki/<formula-slug>/             — формула, пример и Python
/ML/books/                                   — каталог книг
/ML/books/raschka-python-machine-learning/   — С. Рашка
/ML/books/yildirim-mastering-transformers/   — С. Йылдырым, М. Асгари-Ченаглу
```

Конспект Рашки организован по проверенным страницам русского издания. Для книги о Transformer пока используется последовательность по темам глав: номера страниц появятся только после сверки с конкретным изданием пользователя.

## Сборка

Исходные карточки лежат в `data/`. Генератор создаёт каталог, страницы формул, книжные маршруты, Python-файлы и карту сайта:

```powershell
node .\scripts\build-site.cjs --verify-python
```

Флаг `--verify-python` запускает каждый пример и сохраняет его фактический вывод в `data/python-results.json`.

## Как добавить книгу

1. Добавить формулы и книжные примеры в отдельный файл `data/*.js`.
2. Описать книгу, порядок блоков и контекст чтения в `data/books.cjs`.
3. Добавить самостоятельные примеры в `data/python-examples.cjs`.
4. Если формула уже есть в вики, указать её канонический `id` в `FORMULA_ALIASES` генератора, чтобы не создавать дубль.
5. Запустить сборку с проверкой Python и проверить новые маршруты в браузере.

## Источники и права

В репозитории публикуются математические факты, собственные объяснения и самостоятельно составленные учебные примеры. Текст книг, сканы и PDF не копируются. Номер страницы указывается только после сверки с конкретным изданием.
